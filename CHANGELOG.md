# Changelog

## 0.2.7

- Require an AnyaCSV language mode or explicit per-file activation for `.txt` files instead of treating the extension alone as delimited data.

## 0.2.6

- Move fixed-delimiter coloring to TextMate grammars for viewport-first rendering and ten-column color cycling.
- Add range-based semantic coloring for Dynamic CSV, including custom delimiters and multiline quoted fields.
- Use theme scopes for coloring and document grammar limitations and language-mode conflicts.

## 0.2.1

- Add a Privacy section linking to the project privacy policy.

## 0.2.0

- Rename commands and settings to use the Anya namespace. Update any saved command references and setting keys to the new IDs.
